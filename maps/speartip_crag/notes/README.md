# Speartip Crag (map package)

4U m08 as an alias of GU stage 18 (the Sanctuary), stage folder m29. Built by `maps/speartip_crag/build.py`
(`tools/build_speartip.py`, then `tools/build_speartip_ui.py`). Required by Dalamadur (both variants).

Its study stays with the port that made it: `monsters/dalamadur/notes/speartip-crag.md` (stage, music, breakables).
The breakables are posted by core code: `monsters/dalamadur/module/dala_stage.c`, `module/stage_alias.c`.
